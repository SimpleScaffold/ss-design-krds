# 스타일 검증 준수기준

## color

### `style.color.1`

- **tier**: 정부상징
- **automation**: browser (`style-color-palette`)
- **spec**: [docs/style/색상.md](../../docs/style/색상.md)
- 디지털 정부 디자인 시스템의 Primary, Secondary, Gray, System 색상 팔레트와 색상값을 사용하고 있다.

### `style.color.2`

- **tier**: 정부상징
- **automation**: browser (`style-color-palette`)
- **spec**: [docs/style/색상.md](../../docs/style/색상.md)
- 디지털 정부 디자인 시스템의 각 컴포넌트에 정의된 상호작용 상태 표현 색상과 방식을 적용하고 있다.

### `style.color.3`

- **tier**: 정부상징
- **automation**: browser (`style-color-palette`)
- **spec**: [docs/style/색상.md](../../docs/style/색상.md)
- 디지털 정부 디자인 시스템에 정의된 배경 색상을 사용하고 있다.

### `style.color.1`

- **tier**: 자체상징
- **automation**: browser (`style-interaction-color`)
- **spec**: [docs/style/색상.md](../../docs/style/색상.md)
- 상호작용 상태를 표현할 때, 기본 상태 색상을 기준으로 한 증·감 규칙을 적용하고 있다.

### `style.color.2`

- **tier**: 자체상징
- **automation**: browser (`style-interaction-color`)
- **spec**: [docs/style/색상.md](../../docs/style/색상.md)
- 시스템 상태를 표현할 때, 시스템 색상의 색상 범주와 의미 체계를 따르고 있다.

### `style.color.1`

- **tier**: 공통
- **automation**: browser (`style-color-consistency`)
- **spec**: [docs/style/색상.md](../../docs/style/색상.md)
- 배경 색상을 일관성 있게 표현하고 있다.

### `style.color.2`

- **tier**: 공통
- **automation**: browser (`style-color-consistency`)
- **spec**: [docs/style/색상.md](../../docs/style/색상.md)
- 액션, 선택, 입력 컴포넌트의 테두리를 일관성 있게 표현하고 있다.

### `style.color.3`

- **tier**: 공통
- **automation**: browser (`style-color-consistency`)
- **spec**: [docs/style/색상.md](../../docs/style/색상.md)
- 텍스트 색상을 일관성 있게 표현하고 있다.

## shape

### `style.shape.1`

- **tier**: 정부상징
- **automation**: browser (`style-radius-gov`)
- **spec**: [docs/style/형태.md](../../docs/style/형태.md)
- 디지털 정부 디자인 시스템에 정의된 형태 규칙 및 규격을 사용하고 있다.

### `style.shape.1`

- **tier**: 자체상징
- **automation**: browser (`style-radius-scale`)
- **spec**: [docs/style/형태.md](../../docs/style/형태.md)
- 컨테이너 크기가 커질수록 둥글기 값이 커지도록 표현하고 있다.

### `style.shape.1`

- **tier**: 공통
- **automation**: browser (`style-radius-clip`)
- **spec**: [docs/style/형태.md](../../docs/style/형태.md)
- 컨테이너의 둥글기 사용에도 내부 콘텐츠가 가려지거나 잘림 없이 표시되고 있다.

## typography

### `style.typography.1`

- **tier**: 정부상징
- **automation**: browser (`style-font-gov`)
- **spec**: [docs/style/타이포그래피.md](../../docs/style/타이포그래피.md)
- Pretendard GOV 서체를 사용하고 있다.

### `style.typography.2`

- **tier**: 정부상징
- **automation**: browser (`style-font-gov`)
- **spec**: [docs/style/타이포그래피.md](../../docs/style/타이포그래피.md)
- 본문의 기본 텍스트 크기를 17px 이상으로 표현하고 있다.

### `style.typography.3`

- **tier**: 정부상징
- **automation**: browser (`style-font-gov`)
- **spec**: [docs/style/타이포그래피.md](../../docs/style/타이포그래피.md)
- 디지털 정부 디자인 시스템에 정의된 서체 사용 규격을 적용하고 있다.

### `style.typography.4`

- **tier**: 정부상징
- **automation**: browser (`style-font-gov`)
- **spec**: [docs/style/타이포그래피.md](../../docs/style/타이포그래피.md)
- 각 서체 굵기에 맞는 폰트 파일을 사용하고 있다.

### `style.typography.1`

- **tier**: 자체상징
- **automation**: browser (`style-font-self`)
- **spec**: [docs/style/타이포그래피.md](../../docs/style/타이포그래피.md)
- 본문의 기본 텍스트 크기를 16px 이상으로 표현하고 있다.

### `style.typography.2`

- **tier**: 자체상징
- **automation**: browser (`style-font-self`)
- **spec**: [docs/style/타이포그래피.md](../../docs/style/타이포그래피.md)
- 고딕 계열 서체를 사용하고 있다.

### `style.typography.3`

- **tier**: 자체상징
- **automation**: browser (`style-font-self`)
- **spec**: [docs/style/타이포그래피.md](../../docs/style/타이포그래피.md)
- 서체의 굵기를 2가지로 구분하여 표현하고 있다.

### `style.typography.1`

- **tier**: 공통
- **automation**: browser (`style-font-common`)
- **spec**: [docs/style/타이포그래피.md](../../docs/style/타이포그래피.md)
- Title과 Heading 텍스트를 본문보다 굵거나 크게 표현하고 있다.

### `style.typography.2`

- **tier**: 공통
- **automation**: browser (`style-font-common`)
- **spec**: [docs/style/타이포그래피.md](../../docs/style/타이포그래피.md)
- 서체 사용 규칙을 일관되게 적용하고 있다.

### `style.typography.3`

- **tier**: 공통
- **automation**: browser (`style-font-common`)
- **spec**: [docs/style/타이포그래피.md](../../docs/style/타이포그래피.md)
- 여러 줄로 구성된 텍스트의 행간을 텍스트 크기의 1.5배 이상으로 표현하고 있다.
